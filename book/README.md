# Book idea (parked)

Kept for later. This is an illustrated book of everyday moments (people, not screens) that turn out to behave like
software, grouped into nine question chapters.

> *You've already lived it. Programmers just have a name for it.*

It's the mirror image of the Shorts. The Shorts take the software out of its disguise (the app screen). The book
finds software disguised as everyday life, so its rule is the opposite: **no screens in the story**.

- [`IDEATION.md`](IDEATION.md): the pitch, reader, chapters and entries (draft 5)
- [`MOMENTS.md`](MOMENTS.md): every entry explained
- [`UNSURE.md`](UNSURE.md), [`IDEATION_REVIEW.md`](IDEATION_REVIEW.md): the review rounds

These files mention `SERIES_GUIDE.md` and `EPISODES.md` from the story era. Those versions are in git history at commit
`909a12c`.
